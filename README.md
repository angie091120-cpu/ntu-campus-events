# 校園活動網站 - 使用說明

## 快速開始

### Windows
1. 把所有檔案放在同一個資料夾
2. **雙擊 `start-windows.bat`**
3. 瀏覽器會自動打開網站

### Mac
1. 把所有檔案放在同一個資料夾
2. 第一次使用：在 `start-mac.command` 上**按右鍵 → 打開**
3. 之後直接雙擊即可

## 試算表欄位說明

13 個欄位，順序可調但名稱要對得起來：

| 欄位 | 是否必填 | 說明 |
|---|---|---|
| id | 必填 | 唯一識別碼，例：e1、e2、e3 |
| 標題 | 必填 | 活動名稱 |
| 類型 | 必填 | 講座 / 工作坊 / 社團活動 / 表演 / 運動 / 競賽（要跟 events.js 的 EVENT_TYPES 對應） |
| 日期 | 必填 | YYYY-MM-DD 格式 |
| 時間 | 選填 | 例：14:00 – 17:00 |
| 地點 | 必填 | 建議用「建築物對照表」上的名稱（會自動帶入座標） |
| x座標 | 選填 | 0-1 的數字，留空會用地點自動查表 |
| y座標 | 選填 | 同上 |
| 描述 | 選填 | 活動內容簡述 |
| 連結 | 選填 | 活動詳情頁網址（粉專、海報等） |
| 主辦單位 | 選填 | 例：電機資訊學院 AI 中心 |
| 需要報名 | 選填 | 「是」、「否」、「Y」、「N」、「TRUE」、「FALSE」都可以 |
| 報名連結 | 選填 | 報名表單網址 |

### 報名顯示邏輯

- 「需要報名」=「是」+ 有「報名連結」→ 顯示「立即報名 →」按鈕
- 「需要報名」=「是」+ 沒「報名連結」→ 顯示「⚠ 需報名」標籤
- 「需要報名」=「否」→ 顯示「自由參加」綠色標籤
- 「需要報名」空白 → 不顯示任何報名資訊

## 修改活動類型

打開 `events.js`，找到開頭的 `EVENT_TYPES` 陣列：

```javascript
const EVENT_TYPES = [
  { id: 'lecture',     name: '講座',     color: '#2E5BBA' },
  // 新增一行：
  { id: 'exhibition',  name: '展覽',     color: '#7B4FB8' },
];
```

- **id**：英文小寫，不能跟現有的重複
- **name**：中文，要跟試算表「類型」欄填的字一模一樣
- **color**：六位 hex 色碼（可以到 https://htmlcolorcodes.com/ 挑顏色）

存檔，重新整理頁面（網站重新部署）就生效。

## 修改 / 新增建築物對照

打開 `coord-picker.html`：
- 滑鼠點地圖標記 → 選中 → 再點地圖正確位置 → 自動移動
- 「+ 新增建築」按鈕 → 輸入名稱 → 點地圖位置
- 「匯出 CSV」→ 複製→ 貼到 Google Sheet 的「建築物」分頁（如果有用第二個分頁的話）
